# CodeAlpha URL Shortener

A simple URL shortening web application built with Python, Flask, and SQLite as part of the CodeAlpha Backend Development Internship.

## Features

- Accepts long URLs
- Generates unique short codes
- Stores URLs and short codes in SQLite
- Redirects short URLs to the original URLs
- Validates URL input
- Simple web interface
- REST API endpoint for URL shortening

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
